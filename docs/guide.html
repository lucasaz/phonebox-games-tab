Games tab: choosing what counts as a game

The Games tab shows FPS, play time and hardware stats for the game you are playing. A small background program (the collector, PhoneBoxGamesTab.exe) decides which program is the game. Three plain-text files let you fine-tune that decision.

How the collector decides

Every second it looks at the window in the foreground. That program becomes the game when it is drawing at least 5 frames per second and the first matching rule below says yes:

  1. ignore.txt: never a game. This rule always wins.
  2. include.txt: always a game.
  3. Microsoft Store / Xbox apps: a game only if the Microsoft Store catalog lists it as a game (so WhatsApp, Netflix and similar apps are left out automatically).
  4. Known game folders on any drive: steamapps\common, Epic Games, XboxGames, GOG Games, Ubisoft Game Launcher\games, EA Games, Riot Games, Games.
  5. folders.txt: any program inside these folders.
  6. Fullscreen: a window covering its whole monitor (only when no other game is open).

Browsers, Discord, Teams, Wallpaper Engine, launchers (Steam, Epic, Battle.net, EA, Ubisoft, GOG) and similar programs are already ignored by a built-in list.

The three files

They sit in the Games Tab folder, next to the bin folder that holds the collector. The Portuguese names incluir.txt, ignorar.txt and pastas.txt work too.

FileWhat goes in itExample line
include.txtPrograms that must always count as games (installed somewhere unusual, running in a window).MyGame.exe
ignore.txtPrograms that must never count as games (tools, video players, apps).GPU-Z.exe
folders.txtFolders where you install games. Everything inside counts.D:\Games or E:\

Rules for the lines

One entry per line. Everything after # is a comment. Upper/lower case does not matter, and .exe is optional (GPU-Z = gpu-z.exe). Folders may be written with or without the final \.

Example ignore.txt

WhatsApp.Root.exe   # WhatsApp (Store)
GPU-Z.exe
SyncTrayzor.exe     # sync tool on E:\

Find a program's .exe name

Open the program, then Task Manager → Details and read the Name column. Or, in PowerShell:

Get-Process | Where-Object MainWindowTitle | Select-Object ProcessName, MainWindowTitle

Apply your changes

The lists are read only when the collector starts, so restart it after editing: Task Scheduler → PhoneBox Games Tab → End, then Run. Or, in PowerShell:

Stop-ScheduledTask 'PhoneBox Games Tab'; Start-ScheduledTask 'PhoneBox Games Tab'

Good to know. When a program is added to ignore.txt, its old sessions are also removed from the history (week chart and recent sessions) the next time the collector starts.

Troubleshooting

ProblemWhat to do
Game not detectedPut its folder in folders.txt or its .exe in include.txt; make sure the game window is in front.
App shown as a gameAdd its .exe to ignore.txt.
FPS stays emptyYour Windows user must be in the Performance Log Users group (then sign out and in). An administrator can add it with Add-LocalGroupMember -SID S-1-5-32-559 -Member <user>.
Check what draws framesbin\PhoneBoxGamesTab.exe --test lists the frames per second of each program for 5 seconds.
Português (Brasil)

Aba Games: o que conta como jogo

A aba Games mostra FPS, tempo de jogo e dados do hardware do jogo que você está jogando. Um programa pequeno em segundo plano (o coletor, PhoneBoxGamesTab.exe) decide qual programa é o jogo. Três arquivos de texto deixam você ajustar essa decisão.

Como o coletor decide

A cada segundo ele olha a janela que está em primeiro plano. Esse programa vira o jogo quando está desenhando pelo menos 5 quadros por segundo e a primeira regra abaixo que se aplica diz sim:

  1. ignorar.txt: nunca é jogo. Esta regra sempre vence.
  2. incluir.txt: sempre é jogo.
  3. Apps da Microsoft Store / Xbox: só é jogo se o catálogo da Microsoft Store disser que é jogo (assim WhatsApp, Netflix e apps parecidos ficam de fora sozinhos).
  4. Pastas de jogos conhecidas, em qualquer disco: steamapps\common, Epic Games, XboxGames, GOG Games, Ubisoft Game Launcher\games, EA Games, Riot Games, Games, Jogos.
  5. pastas.txt: qualquer programa dentro dessas pastas.
  6. Tela cheia: uma janela que cobre o monitor inteiro (só quando não há outro jogo aberto).

Navegadores, Discord, Teams, Wallpaper Engine, launchers (Steam, Epic, Battle.net, EA, Ubisoft, GOG) e programas parecidos já são ignorados por uma lista interna.

Os três arquivos

Ficam na pasta do Games Tab, ao lado da pasta bin, onde está o coletor. Os nomes em inglês (include.txt, ignore.txt, folders.txt) também valem.

ArquivoO que colocarExemplo de linha
incluir.txtProgramas que sempre devem contar como jogo (instalados num lugar diferente, rodando em janela).MeuJogo.exe
ignorar.txtProgramas que nunca devem contar como jogo (ferramentas, players de vídeo, apps).GPU-Z.exe
pastas.txtPastas onde você instala jogos. Tudo dentro delas conta.D:\Jogos ou E:\

Regras das linhas

Um item por linha. Tudo depois de # é comentário. Maiúsculas e minúsculas tanto faz, e o .exe é opcional (GPU-Z = gpu-z.exe). Pastas podem ter ou não a \ no fim.

Exemplo de ignorar.txt

WhatsApp.Root.exe   # WhatsApp (Store)
GPU-Z.exe
SyncTrayzor.exe     # sincronização no E:\

Descobrir o nome do .exe

Abra o programa e vá em Gerenciador de Tarefas → Detalhes; o nome está na coluna Nome. Ou, no PowerShell:

Get-Process | Where-Object MainWindowTitle | Select-Object ProcessName, MainWindowTitle

Aplicar as mudanças

As listas só são lidas quando o coletor inicia, então reinicie-o depois de editar: Agendador de Tarefas → PhoneBox Games Tab → Finalizar e depois Executar. Ou, no PowerShell:

Stop-ScheduledTask 'PhoneBox Games Tab'; Start-ScheduledTask 'PhoneBox Games Tab'

Bom saber. Quando um programa entra no ignorar.txt, as sessões antigas dele também saem do histórico (gráfico da semana e sessões recentes) na próxima vez que o coletor iniciar.

Problemas comuns

ProblemaO que fazer
Jogo não apareceColoque a pasta dele no pastas.txt ou o .exe no incluir.txt; confira se a janela do jogo está na frente.
App aparece como jogoColoque o .exe dele no ignorar.txt.
FPS fica vazioSeu usuário do Windows precisa estar no grupo Usuários de log de desempenho (depois saia e entre de novo). Um administrador adiciona com Add-LocalGroupMember -SID S-1-5-32-559 -Member <usuário>.
Ver quem desenha quadrosbin\PhoneBoxGamesTab.exe --test mostra por 5 segundos os quadros por segundo de cada programa.
